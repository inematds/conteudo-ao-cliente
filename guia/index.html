Em resumo

Esta página junta cinco peças que já existem separadas no INEMA (o clube gratuito de IA em inema.club) e mostra como elas se encaixam. São quatro ferramentas gratuitas, que rodam no terminal do seu computador com a ajuda do Claude Code (um assistente de IA que trabalha ali), e um curso curto. Servem para quem cria conteúdo (sozinho ou numa empresa pequena) e se perde entre escolher o assunto, produzir, publicar e responder. Cada peça cuida de uma etapa: achar a pauta do dia, ver o que já funcionou nos seus canais, montar o carrossel, entregar o material para quem comenta e passar o resto da rotina para um agente. Cada uma tem o seu guia e funciona sozinha. Você pode usar uma só ou as cinco juntas.

⚠️ Antes de instalar: elas vêm configuradas para o INEMA

As quatro ferramentas são as que o INEMA usa no dia a dia e saem como estão aqui. O radar só tem pautas de inteligência artificial. Os textos gerados (manchetes, ideias, guias e respostas) saem em português, alguns na voz de quem ensina IA. O carrossel vem com a marca, as cores e a capa do INEMA, e a página do lead-comenta leva o nome INEMA no título e no rodapé. Trocar nome, @ e hashtags é fácil (no PERFIL.md do carrossel). Cores, idioma e o resto pedem mexer nos arquivos, e o Claude Code pode fazer isso com você. Se você cria conteúdo de IA em português, servem como estão. No carrossel, o slide final sugere um link do inema.club como material grátis (troque pelo seu), e a capa leva a marca INEMA.CLUB; não peça para ele "postar", porque a postagem automática dele usa a conta do INEMA.

O que é

Um caminho, cinco peças

O problema não é falta de ideia. É ter de decidir tudo do zero todo dia. Aqui cada decisão chata vira um comando.

🧭 Uma etapa por peça

Pauta, ideia, post, contato e rotina. Cada ferramenta faz uma coisa só e entrega um resultado que dá para conferir.

💸 Sem API paga

As ferramentas leem fontes públicas (sites de notícias, o feed público do YouTube) e usam o Claude Code ou o Codex pela sua assinatura.

✋ Você aprova antes

O automático é a preparação: pauta, ideias, slides e respostas saem prontos. Nada é postado nem enviado sozinho; você olha e decide o que sai.

Como funciona

A ordem do dia de quem posta

As peças seguem a ordem natural do trabalho. A saída de uma vira a entrada da próxima, mas nenhuma depende da outra para rodar.

📡 O que está quente hoje→ 📈 O que já funcionou comigo→ 🖼️ O post pronto→ 💬 Quem comenta recebe o material→ 🧹 A rotina com um agente
As 5 peças

O que cada uma faz

Clique no guia de cada peça para instalar e usar. Todos os guias estão em português, inglês e espanhol.

1

📡 radar-pautas

Lê cerca de 20 fontes de notícias de IA (blogs das empresas, imprensa, Hacker News e Reddit) e os projetos que mais ganharam estrelas no GitHub na semana. Junta a mesma notícia vinda de vários lugares, dá uma nota, confere se o link abre e devolve as 6 pautas mais quentes das últimas 24 horas. Se você pedir, sugere manchete, gancho e formato em português.

Precisa: Python 3. O Claude Code é opcional (só para as manchetes, que saem em português). A fonte "GitHub em alta" só entra com o gh instalado e logado; sem ele, o radar segue com os sites.

Guia GitHub

2

📈 muse-canais

Olha os seus canais do YouTube e mostra quais vídeos recentes estão indo bem acima do normal de cada canal. Calcula quantas visualizações por hora cada vídeo ganha e compara com o vídeo típico do mesmo canal. Os que passam de 2 vezes viram "vencedores" e, se você pedir, viram 8 ideias novas de vídeo.

Precisa: Python 3. As ideias usam o Claude Code pela assinatura. Não usa a API do YouTube.

Guia GitHub

3

🖼️ carrossel-inema

Skill para o Claude Code que faz carrosséis de Instagram e TikTok (as mesmas imagens servem no Facebook). Você dá o tema e recebe a capa, de 5 a 10 slides com uma ideia cada, o slide final com "comenta PALAVRA" e 3 stories, no tamanho certo. Antes de mostrar, confere se algum texto ficou cortado ou pequeno demais.

Precisa: Linux ou Mac (no Windows, pelo WSL, o Linux que roda dentro do Windows), Node.js 18 ou mais novo, Python 3 com Pillow, um Chromium e o Claude Code. Para a capa com arte, o Codex logado na sua conta do ChatGPT. O arquivo PERFIL.md vem com a marca do INEMA (nome, @, fecho e hashtags) e textos em português: troque pelos seus antes do primeiro carrossel.

Guia GitHub

4

💬 lead-comenta

Cria a página do "material grátis" que você promete quando diz "comenta PALAVRA que eu te mando". Você dá a palavra, o tema e uma fonte (uma página ou um texto). Ele escreve um guia curto de 4 a 7 passos só com o que está na fonte, gera a página e os textos prontos para responder o comentário, a mensagem direta e o story.

Precisa: Python 3, Claude Code, o gh e uma conta no GitHub. A página fica no ar pelo GitHub Pages da sua conta, de graça. O guia e as respostas saem em português, e a página gerada tem no rodapé a assinatura do INEMA.CLUB, que a ferramenta ainda não deixa trocar.

Guia GitHub

5

🧹 Curso: Entregue o trabalho chato a um agente

Relatório da semana, contato novo, nota fiscal, cliente novo: tarefas que tomam horas e não pedem genialidade. Em 8 aulas de cerca de 15 minutos (umas 2 horas no total) você acha a primeira tarefa a delegar, escreve a ficha do agente, vê o rascunho antes de qualquer coisa ser enviada, escolhe o modelo certo para cada tarefa e sai com um plano de 30 dias.

Precisa: só ler e praticar. Os exercícios funcionam no chat (ChatGPT, Claude ou Gemini) ou no terminal, sem API paga.

Abrir o curso

Pré-requisitos

O que ter no computador

Nem toda peça pede tudo; veja no card de cada uma. Este é o conjunto completo para as quatro ferramentas, num computador Linux, Mac ou Windows com WSL (o Linux que roda dentro do Windows). Os comandos rodam no terminal, a janela onde se digitam comandos. O guia de cada ferramenta tem a instalação em mais detalhe.

Python 3, Git e gh

O Python roda o radar, o muse e o lead-comenta. O Git baixa os projetos. O gh é o programa do GitHub para o terminal: publica a página do lead-comenta e liga a fonte "GitHub em alta" do radar. Se o Ubuntu não achar o pacote gh, siga cli.github.com.

# Ubuntu ou WSL
sudo apt install python3 git gh
# Mac
brew install python git gh

Node.js 18+, Chromium e Pillow (carrossel)

O Node e o Chromium (um navegador que trabalha sem janela) desenham os slides; o Pillow (complemento de imagem do Python) ajuda na checagem. O Node também instala o Codex. No Ubuntu, o último comando instala as bibliotecas que o Chromium usa; sem elas o setup.sh do carrossel falha.

# Ubuntu ou WSL
sudo snap install node --classic
sudo apt install python3-pil
npx playwright install chromium
sudo npx playwright install-deps chromium
# Mac
brew install node
brew install pillow
brew install --cask google-chrome   # no Mac, o carrossel usa o Google Chrome

No Ubuntu, o npx pode perguntar "Ok to proceed?": responda y.

Claude Code (e Codex, opcional)

O Claude Code é o assistente da Anthropic que trabalha no terminal; aqui ele escreve manchetes, ideias, slides e textos. Instale pelo site oficial, claude.com/claude-code. Precisa de um plano pago do Claude (Pro ou acima) e do login, feito uma vez. O Codex é o equivalente da OpenAI: só faz a arte da capa do carrossel, pela sua conta do ChatGPT. Nenhuma das ferramentas usa chave de API.

# abre e pede o login na primeira vez
claude
sudo npm install -g @openai/codex   # opcional, só para a capa (no Mac, sem sudo)
codex login
Guia de uso · passo a passo

Um dia de conteúdo, do começo ao fim

Os comandos abaixo são os primeiros de cada guia. O guia de cada peça explica as opções e os ajustes.

1

Ache a pauta do dia

O radar mostra as 6 pautas sem gravar nada. Escolha uma.

git clone https://github.com/inematds/radar-pautas ~/projetos/radar-pautas
cd ~/projetos/radar-pautas
python3 radar.py --dry       # 6 pautas, sem gravar
python3 radar.py --angulos   # grava + manchete, gancho e formato (Claude Code)

Com --angulos, o resultado fica em ~/projetos/output/radar-pautas/<data>/radar.html; abra esse arquivo no navegador. O formato sugerido pode ser carrossel ou nomes de formatos de vídeo do INEMA; fora do INEMA, use só a manchete e o gancho.

2

Veja o que já deu certo nos seus canais do YouTube

Baixe o muse e descubra o ID do seu canal (começa com UC), trocando o endereço pelo do seu canal:

git clone https://github.com/inematds/muse-canais ~/projetos/muse-canais
cd ~/projetos/muse-canais
python3 -c "import muse; print(muse.resolver_id('https://www.youtube.com/@meucanal'))"

O arquivo canais.json vem com os canais do INEMA. Abra no editor (nano canais.json), apague tudo e deixe só o seu canal, neste formato (salve com Ctrl+O, Enter e Ctrl+X):

{"meucanal": {"nome": "Meu canal", "url": "https://www.youtube.com/@meucanal", "id": "UC..."}}

Depois rode o muse. O relatório fica em ~/projetos/output/muse-canais/<data>/muse.md.

python3 muse.py --ideias     # relatório + 8 ideias de vídeo

Se nenhum vídeo recente passar de 2 vezes o normal do canal (ou tiver menos de 50 visualizações), o relatório sai sem vencedores e sem ideias. É normal: rode de novo depois de publicar mais.

3

Faça o carrossel

Instale a skill uma vez (skill é um pacote de instruções e scripts que ensina o Claude Code a fazer uma tarefa). Depois, abra o Claude Code e peça: "faz um carrossel sobre <a pauta escolhida>". Ele mostra as imagens prontas para você aprovar; a postagem é sua, à mão. Antes do primeiro, troque a marca do INEMA pela sua no PERFIL.md; você também pode pedir ao Claude Code: "preencha o PERFIL.md comigo".

git clone https://github.com/inematds/carrossel-inema ~/projetos/carrossel-inema
cd ~/projetos/carrossel-inema
bash setup.sh                # tem que terminar em SELFTEST PASS
mkdir -p ~/.claude/skills
ln -s "$PWD" ~/.claude/skills/carrossel-inema   # liga a skill no Claude Code
4

Prepare o material de quem comenta

Antes de postar o "comenta PALAVRA", a página do material tem de estar no ar na sua conta do GitHub, senão as respostas levam um link que não é seu. Faça uma vez só: entre no GitHub, crie a sua cópia, ligue o GitHub Pages (o serviço grátis do GitHub que deixa páginas no ar) e grave o seu endereço. Troque SEU-USUARIO pelo seu nome de usuário, que o gh api user mostra. O --scopes workflow do login dá permissão para publicar a página automaticamente; o guia do lead-comenta explica cada pergunta do login.

git clone https://github.com/inematds/lead-comenta ~/projetos/lead-comenta
cd ~/projetos/lead-comenta
gh auth login --scopes workflow
git config --global user.name "Seu Nome"
git config --global user.email "voce@exemplo.com"
gh api user -q .login           # seu nome de usuário
gh repo create lead-comenta --public --source . --remote meu
git push meu main
gh api -X POST repos/SEU-USUARIO/lead-comenta/pages -f build_type=workflow

Grave o seu endereço para valer em todo terminal novo. No Ubuntu ou WSL:

echo 'export LEAD_BASE_URL=https://SEU-USUARIO.github.io/lead-comenta/paginas' >> ~/.bashrc
source ~/.bashrc

No Mac:

echo 'export LEAD_BASE_URL=https://SEU-USUARIO.github.io/lead-comenta/paginas' >> ~/.zshrc
source ~/.zshrc

A sua cópia vem com a palavra de exemplo AGENTE, que aponta para o endereço do INEMA; use sempre uma palavra sua. Para cada post (troque DICAS, o tema e a fonte pelos seus):

python3 lead.py nova DICAS --tema "6 tarefas chatas que um agente faz" --fonte https://inematds.github.io/empresa-de-ia/guia/
python3 lead.py resposta DICAS    # textos para comentário, direct e story
git add -A && git commit -m "guia DICAS" && git push meu main   # a página vai ao ar

A página leva alguns minutos para aparecer. Abra o link que o lead.py resposta mostra antes de postar o convite.

5

Relatório, contato novo, nota e cliente novo. O curso mostra como montar a ficha do agente e conferir antes de enviar. O plano de 30 dias que aparece no banner é a última aula do curso.

Por onde começar

Comece por uma peça, não pelas cinco

Quem tenta ligar tudo no primeiro dia volta para onde estava. Uma por semana funciona melhor.

Semana 2

Semana 3
Comenta e recebeNum dos carrosséis, use o "comenta PALAVRA" com a página do lead-comenta já no ar.
Semana 4
