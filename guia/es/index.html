En resumen

Esta página reúne cinco piezas que ya existen por separado en INEMA (el club gratuito de IA en inema.club) y muestra cómo encajan. Son cuatro herramientas gratuitas que funcionan en la terminal de tu computadora con ayuda de Claude Code (un asistente de IA que trabaja allí), y un curso breve. Sirven para quienes crean contenido (por su cuenta o en una empresa pequeña) y se pierden entre elegir el tema, producir, publicar y responder. Cada pieza se ocupa de una etapa: encontrar el tema del día, ver qué ya funcionó en tus canales, armar el carrusel, entregar el material a quienes comentan y pasar el resto de la rutina a un agente. Cada pieza tiene su guía y funciona por separado. Puedes usar una sola o las cinco juntas.

⚠️ Antes de instalar: vienen configuradas para INEMA

Las cuatro herramientas son las que INEMA usa a diario y funcionan tal como están aquí. El radar solo incluye temas de inteligencia artificial. Los textos generados (titulares, ideas, guías y respuestas) salen en portugués; algunos usan la voz de quienes enseñan IA. El carrusel viene con la marca, los colores y la portada de INEMA, y la página de lead-comenta lleva el nombre INEMA en el título y en el pie de página. Cambiar el nombre, el @ y los hashtags es fácil (en el PERFIL.md del carrusel). Para cambiar los colores, el idioma y lo demás hay que editar los archivos; Claude Code puede ayudarte. Si creas contenido de IA en portugués, puedes usarlas tal como están. En el carrusel, la diapositiva final sugiere un enlace de inema.club como material gratuito (cámbialo por el tuyo), y la portada lleva la marca INEMA.CLUB; no le pidas que "publique", porque su publicación automática usa la cuenta de INEMA.

Qué es

Un camino, cinco piezas

El problema no es la falta de ideas. Es tener que decidir todo desde cero cada día. Aquí cada decisión tediosa se convierte en un comando.

🧭 Una etapa por pieza

Tema, idea, publicación, contacto y rutina. Cada herramienta hace una sola cosa y entrega un resultado que puedes revisar.

💸 Sin API de pago

Las herramientas leen fuentes públicas (sitios de noticias y el feed público de YouTube) y usan Claude Code o Codex con tu suscripción.

✋ Tú apruebas primero

La automatización prepara el tema, las ideas, las diapositivas y las respuestas. No se publica ni se envía nada por sí solo; tú revisas y decides qué sale.

Las 5 piezas

Qué hace cada una

Entra en la guía de cada pieza para instalarla y usarla. Todas las guías están en portugués, inglés y español.

1

📡 radar-pautas

Lee cerca de 20 fuentes de noticias sobre IA (blogs de empresas, prensa, Hacker News y Reddit) y los proyectos que más estrellas ganaron en GitHub durante la semana. Agrupa las noticias repetidas, les asigna una puntuación, comprueba que el enlace funcione y muestra los 6 temas más destacados de las últimas 24 horas. Si se lo pides, sugiere un titular, un gancho y un formato en portugués.

Necesitas: Python 3. Claude Code es opcional (solo para los titulares, que salen en portugués). La fuente "Tendencias de GitHub" se incluye solo si tienes gh instalado e iniciaste sesión; sin él, el radar sigue usando los sitios web.

Guía GitHub

2

📈 muse-canais

Revisa tus canales de YouTube y muestra qué videos recientes están rindiendo muy por encima de lo habitual en cada canal. Calcula cuántas vistas por hora obtiene cada video y las compara con las del video típico del mismo canal. Los que superan el doble se convierten en "ganadores" y, si se lo pides, en 8 ideas nuevas de video.

Necesitas: Python 3. Las ideas usan Claude Code con tu suscripción. No usa la API de YouTube.

Guía GitHub

3

🖼️ carrossel-inema

Skill para Claude Code que crea carruseles para Instagram y TikTok (las mismas imágenes sirven para Facebook). Tú das el tema y recibes la portada, de 5 a 10 diapositivas con una idea cada una, la diapositiva final con "comenta PALABRA" y 3 stories, en el tamaño correcto. Antes de mostrarlos, comprueba si algún texto quedó cortado o demasiado pequeño.

Necesitas: Linux o Mac (en Windows, mediante WSL, el Linux que funciona dentro de Windows), Node.js 18 o posterior, Python 3 con Pillow, Chromium y Claude Code. Para crear la portada con arte, necesitas Codex con la sesión iniciada en tu cuenta de ChatGPT. El archivo PERFIL.md viene con la marca de INEMA (nombre, @, cierre y hashtags) y textos en portugués: cámbialos por los tuyos antes del primer carrusel.

Guía GitHub

4

💬 lead-comenta

Crea la página del "material gratis" que prometes cuando dices "comenta PALABRA y te lo envío". Tú das la palabra, el tema y una fuente (una página o un texto). Escribe una guía breve de 4 a 7 pasos usando solo lo que dice la fuente, genera la página y prepara los textos para responder el comentario, el mensaje directo y la story.

Necesitas: Python 3, Claude Code, gh y una cuenta de GitHub. La página queda en línea gratis con GitHub Pages en tu cuenta. La guía y las respuestas salen en portugués, y la página generada lleva la firma de INEMA.CLUB en el pie de página, que la herramienta todavía no permite cambiar.

Guía GitHub

5

🧹 Curso: Delega el trabajo tedioso a un agente

Informe semanal, nuevo contacto, factura, nuevo cliente: tareas que llevan horas y no requieren genialidad. En 8 clases de unos 15 minutos (alrededor de 2 horas en total) encontrarás la primera tarea que puedes delegar, escribirás la ficha del agente, revisarás el borrador antes de que se envíe cualquier cosa, elegirás el modelo adecuado para cada tarea y terminarás con un plan de 30 días.

Necesitas: solo leer y practicar. Los ejercicios funcionan en el chat (ChatGPT, Claude o Gemini) o en la terminal, sin API de pago.

Requisitos

Qué necesitas en tu computadora

No todas las piezas necesitan todo; consulta la tarjeta de cada una. Este es el conjunto completo para las cuatro herramientas en una computadora con Linux, Mac o Windows con WSL (el Linux que funciona dentro de Windows). Los comandos se ejecutan en la terminal, la ventana donde se escriben comandos. La guía de cada herramienta explica la instalación con más detalle.

Python 3, Git y gh

Python ejecuta radar-pautas, muse-canais y lead-comenta. Git descarga los proyectos. gh es el programa de GitHub para la terminal: publica la página de lead-comenta y activa la fuente "Tendencias de GitHub" del radar. Si Ubuntu no encuentra el paquete gh, sigue las instrucciones en cli.github.com.

# Ubuntu o WSL
sudo apt install python3 git gh
# Mac
brew install python git gh

Node.js 18+, Chromium y Pillow (carrusel)

Node y Chromium (un navegador que funciona sin ventana) dibujan las diapositivas; Pillow (una biblioteca de imágenes para Python) ayuda a revisarlas. Node también instala Codex. En Ubuntu, el último comando instala las bibliotecas que usa Chromium; sin ellas falla el setup.sh del carrusel.

# Ubuntu o WSL
sudo snap install node --classic
sudo apt install python3-pil
npx playwright install chromium
sudo npx playwright install-deps chromium
# Mac
brew install node
brew install pillow
brew install --cask google-chrome   # en Mac, el carrusel usa Google Chrome

En Ubuntu, npx puede preguntar "Ok to proceed?": responde y.

Claude Code (y Codex, opcional)

Claude Code es el asistente de Anthropic que trabaja en la terminal; aquí escribe titulares, ideas, diapositivas y textos. Instálalo desde el sitio oficial, claude.com/claude-code. Necesitas un plan de pago de Claude (Pro o superior) e iniciar sesión una vez. Codex es el equivalente de OpenAI: solo crea la portada del carrusel, desde tu cuenta de ChatGPT. Ninguna de las herramientas usa una clave de API.

# abre y solicita iniciar sesión la primera vez
claude
sudo npm install -g @openai/codex   # opcional, solo para la portada (en Mac, sin sudo)
codex login
Guía de uso · paso a paso

Un día de contenido, de principio a fin

Los comandos de abajo son los primeros de cada guía. La guía de cada pieza explica las opciones y los ajustes.

1

Encuentra el tema del día

El radar muestra los 6 temas sin guardar nada. Elige uno.

git clone https://github.com/inematds/radar-pautas ~/projetos/radar-pautas
cd ~/projetos/radar-pautas
python3 radar.py --dry       # 6 temas, sin guardar
python3 radar.py --angulos   # guarda + titular, gancho y formato (Claude Code)

Con --angulos, el resultado queda en ~/projetos/output/radar-pautas/<fecha>/radar.html; abre ese archivo en el navegador. El formato sugerido puede ser un carrusel o formatos de video de INEMA; si no trabajas con INEMA, usa solo el titular y el gancho.

2

Revisa qué ya funcionó en tus canales de YouTube

Descarga muse-canais y busca el ID de tu canal (empieza con UC), reemplazando la dirección por la de tu canal:

git clone https://github.com/inematds/muse-canais ~/projetos/muse-canais
cd ~/projetos/muse-canais
python3 -c "import muse; print(muse.resolver_id('https://www.youtube.com/@micanal'))"

El archivo canais.json viene con los canales de INEMA. Ábrelo en el editor (nano canais.json), borra todo y deja solo tu canal con este formato (guarda con Ctrl+O, Enter y Ctrl+X):

{"micanal": {"nome": "Mi canal", "url": "https://www.youtube.com/@micanal", "id": "UC..."}}

Después ejecuta muse-canais. El informe queda en ~/projetos/output/muse-canais/<fecha>/muse.md.

python3 muse.py --ideias     # informe + 8 ideas de video

Si ningún video reciente supera el doble de lo habitual en el canal (o tiene menos de 50 visualizaciones), el informe no mostrará ganadores ni ideas. Es normal: vuelve a ejecutarlo después de publicar más.

3

Crea el carrusel

Instala la skill una vez (una skill es un paquete de instrucciones y scripts que enseña a Claude Code a hacer una tarea). Después, abre Claude Code y pídele: "haz un carrusel sobre <el tema elegido>". Te mostrará las imágenes listas para que las apruebes; tú publicas la publicación manualmente. Antes de crear la primera, cambia la marca de INEMA por la tuya en PERFIL.md; también puedes pedirle a Claude Code: "completa el PERFIL.md conmigo".

git clone https://github.com/inematds/carrossel-inema ~/projetos/carrossel-inema
cd ~/projetos/carrossel-inema
bash setup.sh                # debe terminar en SELFTEST PASS
mkdir -p ~/.claude/skills
ln -s "$PWD" ~/.claude/skills/carrossel-inema   # conecta la skill con Claude Code
4

Prepara el material para quienes comentan

Antes de publicar "comenta PALABRA", la página del material debe estar en línea en tu cuenta de GitHub; de lo contrario, las respuestas incluirán un enlace que no es tuyo. Hazlo una sola vez: entra en GitHub, crea tu copia, activa GitHub Pages (el servicio gratuito de GitHub que publica páginas) y guarda tu dirección. Reemplaza TU-USUARIO por tu nombre de usuario; puedes verlo con gh api user. La opción --scopes workflow del inicio de sesión da permiso para publicar la página automáticamente; la guía de lead-comenta explica cada pregunta del inicio de sesión.

git clone https://github.com/inematds/lead-comenta ~/projetos/lead-comenta
cd ~/projetos/lead-comenta
gh auth login --scopes workflow
git config --global user.name "Tu Nombre"
git config --global user.email "tu@ejemplo.com"
gh api user -q .login           # tu nombre de usuario
gh repo create lead-comenta --public --source . --remote meu
git push meu main
gh api -X POST repos/TU-USUARIO/lead-comenta/pages -f build_type=workflow

Guarda tu dirección para que esté disponible en todas las terminales nuevas. En Ubuntu o WSL:

echo 'export LEAD_BASE_URL=https://TU-USUARIO.github.io/lead-comenta/paginas' >> ~/.bashrc
source ~/.bashrc

En Mac:

echo 'export LEAD_BASE_URL=https://TU-USUARIO.github.io/lead-comenta/paginas' >> ~/.zshrc
source ~/.zshrc

Tu copia viene con la palabra de ejemplo AGENTE, que apunta a la dirección de INEMA; usa siempre una palabra tuya. Para cada publicación (cambia CONSEJOS, el tema y la fuente por los tuyos):

python3 lead.py nova CONSEJOS --tema "6 tareas tediosas que puede hacer un agente" --fonte https://inematds.github.io/empresa-de-ia/guia/es/
python3 lead.py resposta CONSEJOS    # textos para comentario, mensaje directo y story
git add -A && git commit -m "guía CONSEJOS" && git push meu main   # la página queda en línea

La página puede tardar unos minutos en aparecer. Abre el enlace que muestra lead.py resposta antes de publicar la invitación.

Por dónde empezar

Empieza por una pieza, no por las cinco

Quien intenta conectar todo el primer día termina donde empezó. Avanzar una pieza por semana funciona mejor.

Semana 3
